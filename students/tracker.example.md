# Programs Tracker

Copy this file to `students/{student-id}/tracker.md` to start a fresh student
workspace. It begins with no evaluated programs; the agent-led `program`
pipeline adds one row per evaluated institution, program, degree type, and
intake. Do not hand-author generated link columns — the deterministic CV and
statement writers fill the `CV` and `Statement` columns on an approved write.
